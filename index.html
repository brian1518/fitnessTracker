01 · Solo Full-Stack Production Application

Lantern Training: Workout Logger & Progression Engine

Live App GitHub Repo

A Green Lantern and Hevy-inspired workout tracking web application supporting 181 exercises, deterministic double-progression load targets, Epley 1RM analytics, body measurement tracking, and an optional xAI/Grok AI training coach.

Backend, Database & Security Architecture

  • Dual PostgreSQL Adapter (src/backend/db.js): Runs zero-setup embedded PostgreSQL locally via @electric-sql/pglite (with process lockfile protection) and connects to external Render PostgreSQL in production.
  • Transactional Saves & Optimistic Concurrency: Whole workouts save inside SQL transactions in workoutModel.js with stable client IDs for retry idempotency and current_version checks to prevent lost edits across tabs.
  • Session & CSRF Hardening: Uses crypto.scrypt password hashing, hashed 7-day session tokens in PostgreSQL, CSRF tokens on all write endpoints, and Zod request validation.

Progression Engine, AI Coach & QA

  • Deterministic Progression: Evaluates completed working sets (excluding warm-up sets), target rep ranges, RPE/RIR effort, fatigue, and training gaps to compute next-session load or rep targets.
  • Rate-Limited xAI / Grok Adapter: Sends privacy-scoped training history (stripping name and email) to grok-4.7 with JSON-schema validation, a 25s timeout, daily caps in ai_usage, and a deterministic offline fallback.
  • Automated Test Suites: Verified using the native Node.js test runner, JSDOM, and end-to-end Playwright browser tests against an isolated in-memory database.
Tech Stack Node.js 22+, Express.js, PostgreSQL, @electric-sql/pglite, Zod, scrypt, Playwright, JSDOM, xAI API
Deployment Static frontend deployed via GitHub Actions (pages.yml) to GitHub Pages; Express API & PostgreSQL hosted on Render (render.yaml)

03 · Back-End Development Module (BED CA2)

Gamified Wellness Challenge Web Application

A full-stack MVC web application built with Node.js, Express.js, and MySQL that turns real-world wellness habits into an interactive house-progression game with elemental multipliers, a spell shop, and collectible badge bonuses.

Reward Engine & Progression Logic

  • House Sorting & Year Progression: Assigns new users to a house at Year 1 on registration and advances YearLevel automatically as cumulative points cross defined thresholds.
  • Multi-Layer Point Calculation: Computes challenge rewards by combining base points, elemental matchup multipliers (1.5x strong, 1.0x neutral, 0.75x weak), optional active spells, and badge bonuses (1.0x–1.4x).

Anti-Exploit Rules & Relational Schema

  • Cooldown Enforcement: Validates completion timestamps before awarding points so users cannot repeatedly farm the same wellness challenge.
  • Badge & Inventory Gating: Requires ownership of all Death Eater badges before unlocking the Voldemort badge, backed by normalized MySQL tables for inventories, completion logs, and user reviews.
Tech Stack Node.js, Express.js, MySQL, JWT Authentication, bcrypt, REST APIs, MVC Pattern
