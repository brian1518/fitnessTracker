                Lantern Training: Full-Stack Workout Logger & Progression Platform
              


              

                A full-stack fitness tracker for logging workouts across 181 exercises, generating deterministic next-session load/rep targets, tracking body measurements, and querying an optional xAI/Grok training coach. Deployed with a GitHub Pages frontend and a Render Express + PostgreSQL backend.
              


              

                

                  Key Engineering Highlights
                

                
    
                  
  • Dual-Database Architecture: Adapts seamlessly between embedded local PostgreSQL (@electric-sql/pglite) and hosted Render PostgreSQL with versioned, transactional SQL migrations.

    • 
                  
  • Automated Quality Gates: Tested with Node.js test runner, JSDOM, and Playwright browser regression checks.

05 Engineering Philosophy

              
How I approach software and security.

            


            

              

                "Getting an application to run is only the starting point. Structuring routes cleanly, enforcing authentication properly, and verifying how the database handles edge cases is what makes software dependable. I use modern developer tools to prototype and learn faster, but I make sure I understand every query, middleware function, and security check before committing it."
              

            

          


          

            

              
                
              
              
Security by Design

              
From scrypt/bcrypt password hashing and CSRF tokens to Zod schema validation, access control belongs in the core architecture.

            


            

              
                
              
              
First-Principles Understanding

              
I trace through API controllers and SQL transactions step by step so I can debug and explain every part of my code.

            


            

              
                
              
              
Systematic Verification

              
Writing automated Node.js, JSDOM, and Playwright tests alongside Postman and pgAdmin4 verification.

            


            

              
                
              
              
Reliable Ownership

              
Writing clear API documentation and deployment guides so projects remain maintainable and reproducible.
